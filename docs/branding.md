# AuthNAuthZ branding proposals

View `/branding.html` for the original SVG concepts, light/dark wordmarks, palettes and UI typography samples. Switch (option 5) is selected and installed: stepped SVG mark, charcoal navigation, lime actions, IBM Plex Sans interface and IBM Plex Mono data. The app fonts are self-hosted through pinned Fontsource packages; federation login pages load a bundled Plex Sans font. The public font license is included in `/fonts/IBM-Plex-LICENSE.txt`. Other proposals remain available for comparison. Fonts are previewed through Google Fonts and should be self-hosted with their licenses when installing the final brand.
